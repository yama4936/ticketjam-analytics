## 再実行

- 専用DBの TEST_DATABASE_URL を設定して npm test。型検査は npm run typecheck、ビルドは npm run build。
- ChromiumをCDPで起動後、node --env-file=.env scripts/verify-browser.mjs。既定URLは http://127.0.0.1:4381。VERIFY_URL / VERIFY_CDP で変更可能。観測済み公演が2件以上必要。書込み操作なし。管理キーがなければ正常ログインだけ省略。
- TEST_DATABASE_URL を設定し npx tsx scripts/verify-admin-browser.ts。テスト公演を作り、ランダム管理キーの一時APIをlocalhostで起動。管理の書込み操作は専用DBだけで実行。
- 2つのブラウザスクリプトは順番に実行する。同じCDPブラウザのタブを共有するため、同時実行しない。
- 結果は .local/evidence/routes-browser.json と admin-browser.json。画像は selling-1440.png / selling-390.png、グラフ部分は selling-charts-1440.png / selling-charts-390.png。

## 修正した不具合

- 生URLの文字列比較による管理認証の判定を、Fastifyの管理ルート専用スコープへ変更。エンコードされた /api/%61dmin/summary にも認証を適用。
- 戻る/進むで別公演の公式券種や番号条件が残る問題を修正。
- 比較表が全体の再読込に連動しない問題を修正。
- グループ重複の500を409と登録済みの説明へ変更。空白だけの名称も拒否。
- 候補件数のグループ間重複と、観測中件数への終了/停止対象の混入を修正。
- 公演遷移処理の修正中に検出した、同一公演再選択で読み込み表示に留まる問題を修正。
